# javascript-warm_up

Node.js fundamentals: reading command-line arguments, basic control flow, functions, recursion, and module exports. Each script is a tiny standalone exercise run directly from the shell (`#!/usr/bin/node`), building up from printing a string to factorials, array sorting, and exposing a function via `exports`.

## Notable files

| File | Description |
|---|---|
| `2-arguments.js`, `3-value_argument.js` | Detecting and printing CLI arguments via `process.argv` |
| `4-concat.js`, `5-to_integer.js` | String concatenation and `parseInt` conversion of arguments |
| `6-multi_languages_loop.js` | Looping over an array with `for...in` |
| `7-multi_c.js`, `8-square.js` | Loops driven by a numeric CLI argument (repeat lines, print a square) |
| `9-add.js`, `10-factorial.js` | Basic arithmetic and recursive factorial |
| `11-second_biggest.js` | Sorting numeric arguments to find the second-largest value |
| `12-object.js` | Creating and mutating a plain JS object |
| `13-add.js` | Exposing a function to other files with `exports.add` |

📚 See the root [CHEATSHEET.md](../CHEATSHEET.md) for the concepts used here.
